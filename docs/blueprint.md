# **App Name**: GrimAutomata

## Core Features:

- Secure Login Management: Allows users to securely store and manage their MonsterGame MoonID credentials for automated login.
- Configurable Automation Settings: Provides a customizable interface for setting up bot actions and preferences.
- Real-time Activity Logging: Logs the bot's actions in real-time, allowing users to monitor game progression.
- Start/Stop Control: Provides an option to easily start or stop the automated player.

## Style Guidelines:

- Primary color: Dark, desaturated purple (#4E4661) to evoke a gothic, mysterious feel.
- Background color: Very dark gray (#121212) for a strong contrast.
- Accent color: Pale gold (#B3A17B) for highlights and important actions.
- Body and headline font: 'Literata' for a vintage, elegant feel.
- Use dark, stylized icons representing in-game actions and settings.
- Layout inspired by classic game UIs with a modern twist.
- Subtle animations on button presses and status updates.
